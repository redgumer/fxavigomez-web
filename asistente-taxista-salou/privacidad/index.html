1. Finalidad del tratamiento

Los datos se tratan para autenticar al usuario, mantener su sesión y asignar o aplicar los permisos que correspondan según su rol y estado. Determinadas funciones profesionales y administrativas están reservadas a los roles que disponen de esos permisos. Cuando el usuario envía voluntariamente una sugerencia o un informe de fallo, los datos se tratan para atender el mensaje, diagnosticar problemas y mejorar la aplicación.

2. Datos tratados

La aplicación puede tratar los siguientes datos:

  • email asociado a la cuenta;
  • identificador de usuario de Firebase (UID);
  • nombre visible y fotografía de perfil, cuando el proveedor de identidad los facilite;
  • rol y estado de autorización almacenados en Cloud Firestore;
  • contenido escrito voluntariamente en una sugerencia o informe de fallo;
  • versión de la aplicación, versión de Android, fabricante y modelo del dispositivo asociados al mensaje;
  • identificador de instalación de Firebase y metadatos técnicos necesarios para obtener la configuración remota, incluidos país, idioma, zona horaria, versiones de plataforma y sistema operativo, identificadores de la app y datos del agente de Firebase;
  • metadatos del dispositivo, versión de la aplicación y lista de módulos o paquetes de recursos instalados, procesados por Google Play para comprobar actualizaciones.

Los mensajes se asocian al UID y, cuando está disponible, al email de la cuenta. El formulario no adjunta ubicación, coordenadas, contactos, teléfono, archivos, fotografías, capturas de pantalla, historial TaxiData ni contenido de otras aplicaciones.

Para importar el histórico profesional, el usuario puede seleccionar o compartir explícitamente un archivo TaxiData.zip. La aplicación solo recibe lectura sobre ese documento, valida su contenido y guarda los datos importados en su almacenamiento privado local. No usa la API de Google Drive, no puede enumerar otras carpetas o archivos y no transmite el contenido de TaxiData al desarrollador mediante esta función.

Actualmente la aplicación no solicita ni recoge ubicación precisa. Tampoco solicita contactos, SMS, teléfono, datos financieros ni acceso general al almacenamiento personal.

3. Servicios técnicos utilizados

La aplicación permite iniciar sesión mediante proveedores de identidad externos habilitados. Actualmente se encuentran habilitados Google y Microsoft. Firebase Authentication se utiliza para autenticar y mantener la identidad de usuario. Cloud Firestore almacena o consulta el rol y el estado asociados al UID para aplicar los permisos correspondientes y guarda las sugerencias o informes de fallo enviados voluntariamente.

Google, Microsoft y Firebase prestan estos servicios como proveedores técnicos. Su tratamiento de datos se rige también por las condiciones y políticas aplicables a sus servicios.

Firebase Remote Config se utiliza para consultar la versión disponible, la versión mínima compatible y avisos de mantenimiento. Google Play In-App Updates se utiliza para comprobar y completar actualizaciones de instalaciones distribuidas por Google Play.

La configuración del modo turno, la guía inicial y la última versión vista se guardan localmente y no se envían a Firestore.

4. Publicidad, analytics y cesión de datos

  • No se venden datos personales.
  • No se utiliza publicidad ni AdMob.
  • No se realiza seguimiento publicitario.
  • No se utilizan herramientas de analytics actualmente.
  • No hay pagos ni compras dentro de la aplicación.

5. Conservación y seguridad

Los datos de cuenta se conservarán durante el tiempo necesario para mantener la cuenta, aplicar sus permisos y cumplir las obligaciones que resulten aplicables. Las sugerencias e informes de fallo se conservarán durante un máximo de 24 meses desde su resolución, salvo que sea necesario conservarlos durante más tiempo por una obligación legal o para defender reclamaciones.

El acceso se apoya en los mecanismos de autenticación de Google, Microsoft y Firebase. Se limita el tratamiento a los datos necesarios para la finalidad indicada.

6. Derechos del usuario

El usuario puede solicitar el acceso a sus datos, la rectificación de datos inexactos y la supresión de sus datos y de la cuenta asociada. Las solicitudes deberán dirigirse a redgumer@gmail.com.

7. Eliminación de cuenta

La aplicación incluye una pantalla interna desde la que se puede iniciar una solicitud de eliminación y copiar los datos necesarios para enviarla. Esta acción no borra datos automáticamente ni los envía a ningún servidor.

También puedes consultar la página pública de solicitud de eliminación de cuenta.

8. Condiciones del servicio

El uso de la aplicación se regula también mediante las Condiciones del servicio.

9. Cambios futuros

Esta política se revisará si cambian las funciones, permisos, proveedores o categorías de datos tratados. Cualquier activación futura de analytics o solicitud de ubicación requerirá actualizar esta política antes de su uso.

10. Aviso de independencia

Asistente Taxista Salou es una aplicación independiente y no oficial de Redgumer. No pertenece ni está afiliada a ninguna asociación, emisora, administración pública ni entidad oficial del taxi.
